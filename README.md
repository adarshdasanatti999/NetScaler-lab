# NetScaler ADC Lab

## Overview
This repository contains my personal NetScaler ADC lab
configurations, test cases, troubleshooting scenarios,
and network automation projects.

## Lab Environment
- NetScaler ADC VPX
- VMware / EVE-NG
- Ubuntu Linux
- Windows Server, where required
- Lab web servers and test clients

## Topics Covered
- Load Balancing
- Content Switching
- SSL/TLS Offloading
- NetScaler Gateway and VPN
- GSLB
- High Availability
- Troubleshooting and Root Cause Analysis
- Python and NITRO API Automation

## Repository Structure
Each topic contains relevant configuration examples,
test procedures, verification commands, and troubleshooting
notes.

## Disclaimer
All examples are intended for a personal lab environment.
Sensitive credentials, private keys, and confidential
customer information must not be included.
